# Pasif UI adapter örnekleri

Bu kaynaklar main 674ae841c11bd747d8571a0b575d2ae49ac918f3 revizyonundan alınmıştır. Mantine, Material UI, Ant Design ve ortak örnek yardımcılar burada pasiftir; testler teslim ağacına taşınmaz.

Runtime archive/ altından import yapmaz. Kurum adapterını src/adapters/<kurum> altında gerçek paket API’siyle uyarlayıp UI_ADAPTERS içine açıkça kaydedin; örneklerin prop/event/compound davranışını kurum paketi adına varsaymayın.

Mantine examples altındaki iki form-review dosyası yalnız rehberdeki tarihsel native model örneğidir. UI adapterId değiştirerek kurum tasarımına dönüştürülmez.

Tasarım ikon örnekleri ayrı [archive/iconLibrary](../iconLibrary) alanındadır. [Adapter rehberi](../../docs/adapter-onboarding.md) ve [kabul listesi](../../docs/component-adapter-checklist.md) yetkilidir.
