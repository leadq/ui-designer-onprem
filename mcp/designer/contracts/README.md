# Designer teknik kontratları

Bu dizin ürünün JSON, layout, state/flow, native dönüşüm ve MCP işlem anlamlarını açıklar. Çalışma tercihleri veya proje pattern'ları için [prompt dizinini](../../prompts/README.md) kullanın.

Manifest ve bu dosyalar MCP ürününden yüklenir; DESIGNER_PROMPTS_DIR bunları değiştirmez. Ayrılmış kimlikle bir prompt eklemek hatadır. Execution contract, Designer'ın yetkili docs/contracts/README.md kaynağından export/build ile gelir. Gerçek alan kabulü registry/parser/validator tarafından uygulanır; Markdown teknik davranışı tek başına değiştirmez.
