# Dashboard

Grafik registry'de yoksa sahte div grafiği veya yeni paket üretme; eksik bileşeni ve önerilen eşlemeyi bildir.
KPI değerleri, para birimi, artış/azalış anlamı ve dönem ilişkisini koru. Dekoratif renklerden iş kuralı çıkarma.
