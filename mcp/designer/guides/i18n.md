# Çeviri ve react-i18next

Durum: needs-project-input. React kodu yazmadan önce okunur. Hedef proje react-i18next kullanır; yeni çeviri altyapısı kurma.

- Mevcut useTranslation kullanımını, namespace/dosya düzenini ve anahtar isimlendirmesini incele. Projedeki adlandırmayı her yeni translation anahtarında uygula; eksikse ekipten sor.
- Kullanıcıya görünen başlık, label, buton, placeholder, yardım, boş/hata durumu ve erişilebilir isimler çeviriden gelir. JSX veya config içinde sabit UI metni bırakma.
- Dinamik değerleri mevcut interpolation/plural yaklaşımıyla işle; cümleyi parçaları birleştirerek kurma. Tarih/sayı biçimini proje örneğinden al.
- Servisten gelen içerik ve fixture alan değerleri UI çeviri anahtarı değildir. Alan etiketini çevir; kişinin adını veya API verisini anahtara dönüştürme.
- Yalnız Designer JSON üretiliyorsa görünen örnek metni koru; şemada olmayan t(), namespace veya çalıştırılabilir ifade ekleme. Çeviri bağlama React üretiminde hedef projede yapılır.
